## 操作方式

- 顶栏“界面配色”可切换四套颜色；太阳按钮继续切换深浅模式。Settings 内有配色预览卡。
- 顶栏左右面板按钮分别收起/展开两侧；分隔条支持拖动、方向键、Shift 加速和双击恢复默认。
- 中间区域跟随两侧宽度伸缩；移动端继续使用独立抽屉，不强行维持桌面三栏。
- 会话标题是首条问题的确定性摘录，不是模型生成的语义摘要；服务器保留 ID 作为内部标识，但列表主标题不再展示它。
- 别名、置顶、配色和面板偏好仍是浏览器本地信息，并非账号级跨设备同步。
